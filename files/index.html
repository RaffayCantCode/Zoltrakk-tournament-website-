About The Platform

About Zoltrakk Arena

Zoltrakk Arena is a next-generation tournament platform built for friends, school clubs, online communities, and professional organisers who want a real bracket workflow without complicated enterprise tools.

Create a tournament in minutes, share one link, let players join teams, and manage matchups from the admin panel. Every supported game uses role-accurate lineups so your event feels authentic.

  • Create & share: Host sets rules, game, and optional first team; everyone else joins through your tournament link.
  • Team flow: Players can create a new squad or join an existing roster with captain/member roles.
  • Schedule control: Auto-generate pairings, add manual matches, set dates/times, and update results on the Schedule page.
  • Supabase powered: All tournament data is stored in a cloud database for fast worldwide access.
