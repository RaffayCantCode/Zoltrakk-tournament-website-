Relational Database Schema

This application utilizes a PostgreSQL relational database hosted on Supabase. The database contains 5 core tables designed to store user data, tournaments, players, contact requests, and rankings.

1. profiles (User Profile Data)

Extends Supabase Auth users table with specific profiles and settings.

Columns:
- id: UUID (Primary Key, references auth.users)
- first_name: TEXT (Not Null)
- last_name: TEXT (Not Null)
- age: INTEGER
- avatar_url: TEXT (Default '')
- theme_pref: TEXT (Default 'light')
- is_admin: BOOLEAN (Default FALSE)
- best_game: TEXT
- rank: TEXT
- looking_for: TEXT (Default 'both')
- teammates: JSONB (Default '[]')
- created_at: TIMESTAMPTZ (Default NOW())
- updated_at: TIMESTAMPTZ (Default NOW())
CRUD Integration:
  • Create: Triggered automatically via a database function on auth user signup.
  • Read: Fetched on user profile page, header stats, and user manager lists in the Admin panel.
  • Update: Updated when users edit profile preferences, teammates, or toggle theme settings.
  • Delete: Truncated automatically when admins delete users via user panel.

2. tournaments (Event Details & Brackets)

Stores details about created events, registered squads, and matches.

Columns:
- id: TEXT (Primary Key)
- owner_id: UUID (Foreign Key, references profiles.id)
- data: JSONB (Stores nested teams, matches, join requests, and visual configurations)
- created_at: TIMESTAMPTZ (Default NOW())
- updated_at: TIMESTAMPTZ (Default NOW())
CRUD Integration:
  • Create: Host inputs new tournament name and game metadata in the tournament builder page.
  • Read: Loaded on the public Tournaments Browse view, details overlay, and dynamic Schedule pages.
  • Update: Modified on teammate joins, status changes, auto-matching generation, and result submissions.
  • Delete: Deletable by creators under My Hub tournament history.

3. user_players (Personal Squad Rosters)

Stores squads registered by users to quickly enter lineups into brackets.

Columns:
- id: UUID (Primary Key)
- user_id: UUID (Foreign Key, references profiles.id)
- data: JSONB (Stores the array of customized player objects with names, games, ranks, and images)
- created_at: TIMESTAMPTZ (Default NOW())
- updated_at: TIMESTAMPTZ (Default NOW())
CRUD Integration:
  • Create: Form validation on the Squad registry creates new profiles.
  • Read: Displayed on the Players Gallery view and in quick-select tournament signups.
  • Update: Edited when updating player details (e.g. game, rank, image).
  • Delete: Deletable by deleting cards inside the squad management screen.

4. contact_messages (Support Tickets)

Stores support requests and contact forms submitted by platform guests.

Columns:
- id: UUID (Primary Key)
- name: TEXT (Not Null)
- email: TEXT (Not Null)
- dob: TEXT
- message: TEXT (Not Null)
- created_at: TIMESTAMPTZ (Default NOW())
CRUD Integration:
  • Create: Form submission on the Support Desk Contact page inserts logs.
  • Read: Accessible in the Admin panel message tabs for staff review.
  • Update / Delete: Restricted (read-only history logs).

5. leaderboard_entries (Dynamic Standings)

Stores leaderboard stats and ranks for top competing teams.

Columns:
- id: UUID (Primary Key)
- team_name: TEXT (Not Null)
- game: TEXT (Default '')
- wins: INTEGER (Default 0)
- losses: INTEGER (Default 0)
- rank: INTEGER (Default 0)
- notes: TEXT (Default '')
- updated_by: UUID (Foreign Key, references profiles.id)
- created_at: TIMESTAMPTZ (Default NOW())
- updated_at: TIMESTAMPTZ (Default NOW())
CRUD Integration:
  • Create: Admins add teams and initial scores in the Admin panel.
  • Read: Displayed in descending rank on the public Leaderboard.
  • Update: Edited by admin staff when editing records/wins.
  • Delete: Removed by admins using delete controls.
