How to Use MetaMask

1. Install MetaMask — Get the browser extension at metamask.io (Chrome, Firefox, Edge, Brave).

2. Create a wallet — Follow the setup wizard. Save your seed phrase somewhere safe (never share it).

3. Connect to Zoltrakk — When you create a paid tournament or join one with an entry fee, click the MetaMask button. The extension will pop up automatically — review the transaction details and confirm.

4. Safety — Zoltrakk only asks MetaMask to connect an account or approve a visible ETH transaction. Never enter seed phrases, private keys, or wallet passwords on this website.
